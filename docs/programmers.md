# 프로그래머스 통계와 성장 기록

## 표시되는 내용

- 통계 배지: 본인이 발급한 공개 배지 주소를 README에서 표시합니다.
- 성장 그래프: 매일 수집한 누적 풀이 수를 연결합니다.
- 원본 기록: data/programmers-history.csv에 날짜, 누적 풀이 수, 점수, 순위, 스킬 레벨, 수집 시각을 저장합니다.
- 기록은 2026-11-02부터 시작합니다. 연동 이전의 날짜별 통계는 추정하지 않습니다.

## 평소 사용 방법

1. PROGRAMMERS-BADGE-V2가 설치된 Chrome에서 프로그래머스 문제를 풉니다.
2. 확장 프로그램의 '자동 동기화'를 켜 두면 정답 제출을 감지해 배지를 갱신합니다.
3. 갱신이 누락되면 프로그래머스 문제 또는 프로필 탭을 열고 확장 프로그램에서 '다시 동기화'를 누릅니다.
4. GitHub의 성장 그래프는 매일 한국 시간 00:17에 최신 배지 값을 읽습니다. 예약 실행은 지연될 수 있습니다.
5. 바로 기록하려면 이 저장소의 Actions → Update Programmers growth → Run workflow를 실행합니다.

GitHub 작업은 공개 배지의 마지막 동기화 값을 수집합니다. 프로그래머스에 직접 로그인하거나 브라우저 확장 프로그램을 대신 실행하지 않습니다. 다른 브라우저나 기기에서 푼 문제가 아직 배지에 동기화되지 않았다면 그래프에도 반영되지 않습니다.

## 기록 기준

- 날짜와 수집 시각은 한국 시간(KST)을 사용합니다.
- 하루에 한 줄을 남깁니다. 같은 날 다시 수집하면 그날의 최신 값으로 교체합니다.
- 같은 날 값이 변하지 않으면 기존 수집 시각을 보존하며 불필요한 커밋을 만들지 않습니다.
- 수집 실패일은 기록하지 않습니다. 실패를 0문제로 처리하거나 미수집 날짜를 채우지 않습니다.
- 날짜 사이 선은 관측값을 연결한 것이며, 미수집일의 일별 풀이 수를 뜻하지 않습니다.
- 스킬 레벨, 점수, 순위도 CSV에 함께 보존하지만 그래프의 세로축은 누적 풀이 수입니다.
- 배지 SVG 구조가 바뀌거나 서버가 응답하지 않으면 작업을 실패로 표시하고 기존 기록을 유지합니다.

## 관리

- 공개 배지 주소는 scripts/update_programmers.py의 BADGE_URL과 README.md에서 확인할 수 있습니다.
- GitHub 비밀번호, 프로그래머스 비밀번호, 개인 액세스 토큰은 필요하지 않습니다.
- 자동 작업에는 이 저장소에 한정된 GitHub 기본 토큰의 contents: write 권한만 사용합니다.
- 브랜치 규칙이나 Actions 정책이 바뀌어 자동 커밋이 거부되면 Actions 로그에서 확인합니다.
- 공개 저장소는 60일간 저장소 활동이 없으면 예약 작업이 비활성화될 수 있습니다. 중단 시 Actions에서 다시 활성화합니다.
- 풀이 코드 자동 저장은 확장 프로그램의 GitHub 설정에서 별도로 관리합니다. 이 설정은 코드 저장 대상 저장소를 바꾸지 않습니다.
- 알고리즘 풀이 저장소는 https://github.com/y0y00700/algorithm 입니다. 확장 프로그램에서 저장소 목록을 새로고침한 뒤 이 저장소를 선택하고 설정을 저장합니다.
